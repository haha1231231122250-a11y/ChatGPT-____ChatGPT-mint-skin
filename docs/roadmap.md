# Roadmap

## 1.1 — 背景库与选择面板（已完成）

- [x] 皮肤内浮层：18 张缩略图 + 中文名、点选即换、当前项高亮；
- [x] `background.mode` 增加 `"rotate"`（按间隔轮换，面板里可开关与调间隔）；
- [x] 选择/开关/间隔记到 `localStorage`，与 `skin.json` 的默认值分开；
- [ ] 背景亮度/模糊滑块（对应 `background.opacity`、`filter`）；
- [ ] 按"每天"或"每个会话"轮换（现在只有按秒/分钟）。

## 1.2 — 更多主题

- [ ] 把配色抽成 `themes/*.json`（当前是 `skin.json` 的 `palette`），提供 2–3 套预设
      （白/淡绿、夜蓝、樱粉）；
- [ ] `data-ccs-theme` 切换 + 热重载；
- [ ] 侧栏 Q 版与 Sol 表情支持按主题覆盖。

## 1.3 — 平台与健壮性

- [ ] macOS 支持调研（ChatGPT for Mac 的启动参数与进程名不同，需要单独验证 CDP 通道）；
- [ ] 客户端升级后的一键自检：`verify` 失败时给出"哪一层选择器失效"的诊断；
- [ ] 把 `[class*="MarkdownRoot"]` 之类的结构依赖改成多路候选 + 可配置覆盖。

## 已知不做

- 不改安装目录、不重打包 `app.asar`、不接管网络请求；
- 不读取会话内容（只统计正文字符数用于状态判定，不落盘、不外发）。
