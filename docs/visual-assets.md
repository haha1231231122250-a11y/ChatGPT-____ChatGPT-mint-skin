# 美术素材

v1.3.1 的动态壁纸使用完整的双人插画。薄荷花园沿用静态库的「阳光花园里的姐妹茶会」。窗边细雨和月夜萤火使用内置 ImageGen，以同一张茶会插画作为人物和画风参考。三张都放在 `assets/dynamic/` 下，局部轻摇、落叶、雨滴和水纹由渲染层叠加。

- `rain.webp` 使用「保持白蕾丝服饰、淡银发和花饰，Astra 与 Sol 亲近地坐在雨窗前共读图画书，室内是琥珀色灯光，窗外是雨雾花园」。
- `fireflies.webp` 使用「保持同一对角色与水彩绘画质感，两人并肩坐在月光池塘的石沿，Astra 指向萤火，Sol 看着水面微笑，冷色月光映着湖水并有一盏暖灯」。

## v1.3.0 素材记录

三张背景底图与五张 Sol 姿势使用内置 ImageGen 生成。背景输出为 1600 像素宽的 WebP，并另存 400 像素宽的静态缩略图。Sol 姿势保留透明通道，按 768 像素高输出。Astra 表情来自已有角色素材，署名及使用范围见 [NOTICE](../NOTICE)。

| 文件 | 图像生成描述 |
| --- | --- |
| `assets/dynamic/garden.webp` | 原创横向薄荷庭院，奶油色拱门、淡色花朵、柔和日光，中心留白。 |
| `assets/dynamic/rain.webp` | 静谧的薄荷绿窗边，透过雨窗望向花园，窗框、绿植与柔和漫射日光。 |
| `assets/dynamic/fireflies.webp` | 蓝绿色月夜池塘，边缘有芦苇和蕨叶，淡紫月亮倒映水面。 |
| `assets/sol/pose-blink.webp` | 参考现有 Sol 立绘，保留衣着、发型和站姿，轻柔闭眼眨眼。 |
| `assets/sol/pose-wave.webp` | 保留角色设计，抬起一只张开的手友好地挥手。 |
| `assets/sol/pose-think.webp` | 保留角色设计，头微倾，手轻托脸颊。 |
| `assets/sol/pose-stretch.webp` | 保留角色设计，双手向上伸懒腰，神情放松。 |
| `assets/sol/pose-cheer.webp` | 保留角色设计，一手竖大拇指，微笑鼓励。 |

背景均采用淡薄荷插画风格，中心降低细节，不含人物和文字。Sol 姿势以现有透底立绘作为角色参考，保留发夹、衣服配色和人物比例。
